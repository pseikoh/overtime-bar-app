# Overtime Bar-Bestellung

Web-App für die Bars im Eisstadion: Bar auswählen, Sortiment bestellen, Status verfolgen.
Bestellungen gehen über Firebase an das Overtime Lagerprogramm.

Auf dem Tablet: Adresse in Chrome öffnen → Menü ⋮ → „Zum Startbildschirm hinzufügen“ / „App installieren“.
Beim ersten Start den Zugangscode aus dem Lagerprogramm eingeben.
